# Oscar · Yi Li — personal site

Static GitHub Pages site for Yi Li (Oscar), GitHub user [SH0TGUN666](https://github.com/SH0TGUN666).

The site is plain HTML and CSS at the repository root. There is no build step. GitHub Pages can serve it from the `main` branch folder `/` (root).

## Site URL

https://SH0TGUN666.github.io

## Enable or confirm Pages

1. Open this repository on GitHub and go to **Settings**.
2. In the sidebar, open **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch **main** and folder **/ (root)**, then save.
5. After the deployment finishes, the site is available at https://SH0TGUN666.github.io.

A `.nojekyll` file is included so Pages publishes these files as written, without running Jekyll.
